# Arma Commander: Reforger

A fan remake of the Arma 3 "Arma Commander" mode for Arma Reforger.

**Download:** [ArmaCommander-Arland.zip](https://github.com/propst-design/ArmaCommanderReforger/releases/latest/download/ArmaCommander-Arland.zip). Unzip it and open "READ ME FIRST.txt".

The Host and Join launchers update themselves from this page.

Based on Arma Commander for Arma 3 by Martin Hajek (APL-SA).
